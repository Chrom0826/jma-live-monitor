# JMA LIVE MONITOR — 気象庁防災XML 常時ループ型ライブモニター

気象庁（JMA）の防災情報XMLおよび防災オープンデータを自動取得し、スクリーンセーバーのように常時巡回・可視化するクライアントサイド完結型（SPA）ライブモニターです。
特務機関NERV防災ライブのようなサイバー・ダークテイストのUIで、24時間365日完全無料で動作します。

---

## ✨ 主な機能と特徴

1. **常時ループ巡回表示**
   - **高解像度降水ナウキャスト ＆ 雷レーダー**: 過去実況から高解像度予測まで全時間帯を自動アニメーション再生
   - **気象警報・注意報**: 47都道府県の最新発令マップ（鮮やかなイエロー・レッドのコロプレス塗り分け）と地域別リストの自動スクロール
   - **台風解析・進路予報**: 中心位置（×印）、強風域（15m/s）、暴風域（25m/s）、予報円・暴風警戒域・包絡線の表示
   - **全国アメダス気象実況**: 全国約930地点の気温分布グラデーション（重なりゼロの最適化描画）
   - **今後の天気・週間予報**: 全国主要都市の天気・最高/最低気温・降水確率
   - **地震情報・履歴**: 直近20件の地震履歴リストと各地の震度観測点・震源地表示

2. **緊急割り込み機能**
   - **リアルタイム地震速報**: P2P地震情報 WebSocket（`wss://api.p2pquake.net/v2/ws`）により、地震発生時に即座に震源地へカメラが自動飛行して割り込み表示
   - **火山噴火・津波・潮位変化速報**: 噴火警戒レベル変更や異常潮位観測時に自動で該当地域へフォーカス

3. **シームレスな全画面・世界地図対応**
   - 道路や文字のないダークなベクター日本地図＆世界地図（日付変更線越え対応）を内蔵
   - 画面遷移・カメラ飛行中も地図や台風進路が途切れない高速SVGバッファリング描画

4. **下部XML全文FEEDティッカー**
   - 受信した気象庁防災XML電文全文を一行テロップで滑らかに常時スクロール表示

5. **完全無料・クライアントサイド完結（サーバー不要）**
   - 外部有料APIやAIトークン課金は一切なし（利用料金0円）
   - 静的ホスティング（GitHub Pages, Cloudflare Pages, Vercel 等）にそのまま配置可能

## 🚀 ローカルでの実行方法

### 必要環境
- Node.js (v18以上推奨)
- npm / pnpm / yarn / bun

### 手順
```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (ポート 3000)
npm run dev
```

起動後、ブラウザで `http://localhost:3000` を開きます。

---

## 📦 ビルド & デプロイ (GitHub Pages 等)

```bash
# プロダクションビルド
npm run build
```

生成された `dist/` ディレクトリの内容をそのまま GitHub Pages、Cloudflare Pages、Vercel などの静的ホスティングサービスにアップロードするだけで、完全無料でWeb公開できます。

---

## 📡 データソース・謝辞

- **気象庁 (JMA)**: 防災情報XML、高解像度降水ナウキャスト、アメダス観測データ、気象警報・注意報
- **P2P地震情報**: 地震情報 JSON API & WebSocket プッシュ通知
- **Natural Earth**: ベクター世界地図・海岸線データ
